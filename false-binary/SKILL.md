# False Binary Detector

A fast pattern-recognition skill for dissolving artificial either/or framings before they constrain the solution space.

The pattern is common, often unconscious, and frequently load-bearing for whoever benefits from the constrained choice.

---

## The Three Exits

When a binary is identified, there are exactly three ways out. Check all three — more than one may apply.

### 1. Both
Can the options be pursued simultaneously or in parallel? Binary framings often assume mutual exclusivity that doesn't actually exist. If both can be done, do both. Sequence if resources require it, but don't treat sequencing as exclusion.

*This session: diagnostic vs. entrepreneurial. Both. They reinforce each other.*

### 2. Sequence
Can the options be pursued in order, with the first enabling or informing the second? Many false binaries are actually decisions about what to do *first*, not what to do *instead*.

*This session: Codeberg vs. GitHub. Both, with Codeberg first for principle and GitHub as mirror for reach.*

### 3. Transcend
Does the binary dissolve when the underlying requirement is restated at a higher level of abstraction? Sometimes neither option is correct because the question is wrong. Restate the actual goal and derive options from scratch.

---

## Recognition Patterns

False binaries arrive in several forms:

- **Explicit:** "Should I use X or Y?"
- **Implicit:** A recommendation that doesn't mention alternatives, framing one path as obvious
- **Rhetorical:** "You can have security or convenience, not both" — usually vendor-speak for "buy our product"
- **Temporal:** "We need to decide now between A and B" — urgency manufactured to prevent transcendence
- **Consensus:** "Everyone uses X, the alternative is Y" — the middle of the option space has been quietly removed

---

## Adjacent Note

False binaries and enshittification frequently co-occur. A vendor that has successfully installed a false binary in a market has constrained procurement to options they control. The binary is the product.

When both skills fire simultaneously, the false binary is probably the mechanism by which the dependency substitution is being enforced.

---

## Output

When this skill fires:

1. Name the binary explicitly
2. State which exit applies — both, sequence, or transcend
3. Propose the expanded option set in one sentence
4. Continue — do not dwell; the point is to unblock, not to lecture
